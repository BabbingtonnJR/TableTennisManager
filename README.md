# Table Tennis Manager

Sistema de organização de filas para tênis de mesa, com manual de uso e 
levantamento de requisitos funcionais documentados.

## Funcionalidades

- Organização e gerenciamento de filas de jogadores
- Persistência do histórico de partidas/fila

## Tecnologias

Python
